이 저장소는 **[수강하는 수업명]** 또는 **[학기]** IoT 프로그래밍 수업의 학습 자료, 예제 코드, 실습 결과물을 체계적으로 정리하는 공간입니다.

## 🎯 수업 개요 및 목표

* **주요 언어:** Python
* **주요 하드웨어:** [예: Raspberry Pi 4, ESP32 등]
* **목표:**
    1.  파이썬을 이용한 **GPIO 제어 및 센서 데이터 처리** 숙달.
    2.  HTTP, **MQTT** 등의 네트워크 프로토콜을 이용한 **클라우드 연동** 구현.
    3.  실제 IoT 서비스를 설계하고 구현하는 **종합적인 능력** 배양.
